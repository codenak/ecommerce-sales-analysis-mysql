E-Commerce Sales & Customer Analysis

Dataset: UCI Online Retail II (640K+ rows)  
Tool: MySQL  

What this project covers:
- Data cleaning — removed nulls, cancelled orders, encoding errors
- Exploratory analysis — revenue trends, top products, top countries
- Advanced analysis — RFM segmentation, MoM growth, repeat vs one-time customers
- Stored procedure — top 5 customers by country

Key techniques used:
CTEs, Window Functions (RANK, LAG, ROW_NUMBER), Subqueries, Stored Procedures
